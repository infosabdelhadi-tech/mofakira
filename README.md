# مفكرة الإدارة التربوية (MOFAKIRA)

> **نظّم عملك، برمج عملياتك، وتابع إنجازاتك.**
> تطبيق الويب التقدمي (PWA) الذكي والموجّه لمديرات ومديري مؤسسات التعليم الابتدائي بالمملكة المغربية.

---

## 📌 عن المشروع

**مفكرة الإدارة التربوية** هي منظومة رقمية متكاملة صُممت خصيصاً لمساعدة أطر الإدارة التربوية (المدير، المدير المساعد، وهيئة الإدارة) في المؤسسات الابتدائية المغربية على أداء مهامهم الإدارية والتربوية والمالية وفق التوجيهات والمساطر الرسمية لوزارة التربية الوطنية والتعليم الأولي والرياضة.

يعتمد التطبيق نهج **الأولوية للهاتف المحمول (Mobile-First)** مع واجهة عربية كاملة (RTL)، ويعمل بكفاءة تامة على الهواتف الذكية (Android و iPhone)، الحواسيب اللوحية، والأجهزة المكتبية، مع دعم العمل بدون اتصال بالإنترنت (**Offline-First PWA**).

---

## 🌟 الميزات والوحدات الرئيسية

1. **لوحة القيادة الذكية (Dashboard)**:
   - عرض فوري للتاريخ الهجري والميلادي مع تحية مخصصة.
   - مؤشرات وإحصائيات رقمية للمهام، العمليات، والمواعيد.
   - تنبيهات الاستحقاقات القريبة والمواعيد المتأخرة.
   - شريط الوصول السريع لأهم الإجراءات والبحث الفوري.

2. **برنامج العمل السنوي (Annual Work Plan)**:
   - تقسيم زمني مدرسي يغطي أشهر الموسم الدراسي (من شتنبر إلى يوليوز).
   - توزيع العمليات حسب المجالات الرسمية لمشروع المؤسسة المندمج.
   - إمكانية استنساخ ونقل الهيكل إلى مواسم دراسية جديدة.

3. **تدبير المهام (Tasks Management)**:
   - تنظيم المهام الإدارية والتربوية (جديدة، قيد الإنجاز، منجزة، متأخرة).
   - أسلوب عرض جدولي ولوحة كانبان تفاعلية.
   - تصنيفات إدارية معتمدة وتحديد الأولويات والمسؤولين ونسب الإنجاز والمرفقات.
   - الترحيل التلقائي للمهام غير المنجزة.

4. **التقويم والمواعيد (Calendar & Agenda)**:
   - تقويم تفاعلي بطرق عرض متعددة (شهري، أسبوعي، يومي، جدول أعمال).
   - رصد مواعيد مجالس المؤسسة، اللقاءات التربوية، وزيارات المفتشين.
   - كشف تلقائي للتعارضات وتنبيهات مسبقة.

5. **برمجة العمليات الكبرى وتتبعها (Operations Planning)**:
   - تخطيط المشاريع والعمليات المركبة (الدخول المدرسي، الامتحانات الإشهادية، الدعم التربوي...).
   - تقسيم كل عملية إلى مراحل تنفيذية مرتبة زمنياً مع مؤشرات إنجاز دقيقة.

6. **مجالس المؤسسة والقرارات (School Councils)**:
   - إدارة اجتماعات مجالس المؤسسة الأربعة: مجلس التدبير، المجلس التربوي، والمجالس التعليمية، ومجالس الأقسام.
   - تسجيل الحضور، جداول الأعمال، ومحاضر الاجتماعات الرسمية.
   - تتبع القرارات والتوصيات مع إمكانية تحويلها بضغطة زر إلى مهام تنفيذية مرتبطة بالمحضر ومنع التكرار.

7. **المفكرة واليوميات الإدارية (Daily Notebook)**:
   - سجل يومي رقمي لتوثيق الأحداث، الملاحظات التربوية والإدارية، والقرارات الفورية.
   - إمكانية البحث والفرز الزمني والتصدير للطباعة.

8. **مركز الإشعارات والتنبيهات المتقدم (Notifications Center)**:
   - تنبيهات استباقية بالمهام المستحقة والمواعيد القادمة.
   - إمكانية تأجيل التنبيه، تعليمه كمقروء، وتصفية التنبيهات حسب النوع.

9. **التقارير والإحصائيات الرسمية (Official Reports)**:
   - تقارير إدارية متوافقة مع الترويسات الرسمية لوزارة التربية الوطنية والأكاديميات الجهوية.
   - تصدير فوري إلى جداول Excel احترافية (`.xlsx`).
   - تجهيز عالي الدقة للطباعة والحفظ بصيغة PDF بدعم كامل للغة العربية.

10. **الأمان والتخزين المحلي والنسخ الاحتياطي (Local-First Storage)**:
    - حفظ آمن ومحلي لكافة البيانات على جهاز المستخدم (LocalStorage / PWA Cache).
    - معالج تهيئة أولية لبيانات المؤسسة (المدرسة، المديرية، الأكاديمية، الموسم الدراسي).
    - إمكانية تحميل أو تصفير البيانات التجريبية بطلب صريح ومنفصل.
    - تصدير واسترجاع نسخة احتياطية شاملة بصيغة JSON مع التحقق الصارم من سلامة الملف.

## 🛠️ البنية التقنية

- **الواجهة الأمامية**: React 19، TypeScript، Vite.
- **التصميم والتنسيق**: Tailwind CSS v4، أيقونات Lucide React، خطوط Cairo و Tajawal.
- **تصدير البيانات**: مكتبة `xlsx` لجداول البيانات، ونسق طباعة متقدم لـ PDF.
- **معمارية العمل دون إنترنت**: Service Worker مخصص و Web App Manifest لتثبيت PWA على مختلف الأجهزة.

## 🚀 التثبيت والتشغيل المحلي

### المتطلبات الأساسية
- Node.js (الإصدار 18 فما فوق).
- مدير الحزم `npm` (أو `pnpm` أو `yarn`).

### خطوات التشغيل
1. استنساخ المستودع:
```bash
git clone https://github.com/username/mofakira.git
cd mofakira
```

2. تثبيت الحزم:
```bash
npm install
```

3. تشغيل خادم التطوير المحلي:
```bash
npm run dev
```
افتح الرابط الظاهر في الطرفية (عادةً `http://localhost:5173`) عبر متصفحك.

4. بناء النسخة الإنتاجية:
```bash
npm run build
```

5. فحص الشيفرة المصدرية (Linting):
```bash
npm run lint
```

## 📱 التثبيت كتطبيق مستقل (PWA)

- **على هواتف Android**: افتح التطبيق في متصفح Chrome أو Edge واضغط على خيار «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».
- **على هواتف iPhone (iOS)**: افتح التطبيق في متصفح Safari واضغط على زر المشاركة ثم اختر «إضافة إلى الشاشة الرئيسية».
- **على الحواسيب المكتبية**: يظهر زر التثبيت في شريط العنوان بالمتصفح لتثبيت التطبيق كنافذة مكتبية مستقلة تعمل دون إنترنت.
